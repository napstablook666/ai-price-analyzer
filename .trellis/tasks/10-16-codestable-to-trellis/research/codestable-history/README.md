# Historical CodeStable Work Records

This directory preserves all nine records copied from `.codestable/work/`. Each record has a short migration notice at its beginning; the original record body follows unchanged.

These documents describe their original sessions. Test counts, commit references, online API observations, branch/worktree state, and reports of concurrent edits are historical snapshots, not current project rules or current repository status. For current conventions, use the Trellis frontend specifications; for the station registration and check-in lessons, see the relevant curated spec sections.

The source directory was removed only after checking that every listed source file had a destination and that removing each destination's notice yielded a byte-for-byte match with its original source. The complete source-to-destination inventory is in `../migration-map.md`.
