# 公益站适配与付费中转站切换

## Goal

让用户在同一份价格分析里快速切换「付费中转站」和「公益站」，并把公开模型广场作为独立公益来源展示。公益站不参与付费中转站或官方价格对比，默认用于查看同一公益站内不同模型的价格差异。

## Confirmed facts

- 公益站通常不直接收费，可能消耗虚拟积分；大多数站点通过签到获得额度。
- 公益站之间的计价比例可能不同，首版统一按 `1:1` 处理，避免把积分、额度和人民币价格误当成同一货币。
- 公益站需要单独比较：公益站只与公益站归组，不和付费中转站、官方价格混比。
- Linux.do Marketplace 作为一个独立预置的公益站接入，不拆成多个站点；数据入口共享，站内模型继续作为多行价格数据展示。
- `https://windhub.cc/pricing` 作为第二个独立预置公益站接入，按页面公开的价格接口读取模型价格。
- 大多数场景优先查看同一家公益站的不同模型价格，UI 需要支持按站点筛选。

## Requirements

### R1. 公益站适配

- 预置 Linux.do Marketplace 公益站使用公开读取策略，不发送用户认证凭证；当前研究确认价格查询依赖 `/admin/graphql` 和登录态 Bearer token，未确认匿名价格接口，因此首版只提供安全可见的延期预置，不伪造价格数据。
- 预置 WindHub 公益站，读取 `GET https://windhub.cc/api/pricing` 的公开 JSON 数据。
- 两个站点都归类为 `public`，默认启用；站点数据失败时只影响该站点，并显示可理解的错误状态。
- 适配层将模型名、输入价、输出价、缓存价、分组/计费信息映射到现有标准化价格结构。
- 公益站价格货币保留为站点原始积分/额度单位；首版充值/兑换比例默认 `1:1`，不可据此推断人民币成本。
- WindHub 需要保留各模型的输入/输出倍率、缓存倍率、分组倍率和端点信息；`/api/pricing` 当前返回 `success`、`data`、`group_ratio`、`usable_group`、`vendors` 等字段。

### R2. 公益站比较边界

- 公益站的比较分组固定为 `public`，同一标准模型下只比较公益站报价。
- 公益站不显示「低于官方」「高于官方」及官方价格列；月成本/差额不伪装成付费货币成本。
- 允许同一公益站内的不同模型按统一的站点积分单位排序、筛选和查看；不同公益站之间只在单位相同且有明确标识时展示横向价格关系，否则仍以各站点独立查看为主。
- 付费中转站继续保留现有官方价格对比和推荐逻辑，不受公益站数据污染。

### R3. 付费/公益快捷切换

- dashboard 顶部或工具栏提供明确的二态切换控件：`付费中转站` / `公益站`。
- 切换后只展示对应比较分组的行、筛选项、摘要和空状态；不能只改变标签而继续混入另一分组。
- 默认打开 `付费中转站`，保留现有用户的默认工作流；切换状态在刷新或重新打开 dashboard 后保持。
- 公益站模式下优先支持站点筛选，方便查看同一家公益站的不同模型价格。
- 控件必须支持键盘操作、可见焦点、屏幕阅读器状态，并满足现有响应式布局，不产生横向滚动。

### R4. 站点配置兼容

- 复用现有站点 `category: "public"` 语义、预置注册、迁移和快照链路，不另造并行配置格式。
- 公益站预置可被用户禁用、刷新；用户已有自定义站点和已保存快照不被破坏。
- 公开模型价格请求使用 `credentials: "omit"`，不读取或上传用户密钥。

## Acceptance Criteria

- [ ] 首次安装或清空配置后，站点设置中能看到 Linux.do Marketplace 和 WindHub 两个公益站预置，类型显示为「公益中转站」，且默认启用。
- [ ] 首次刷新公益站后，WindHub 能生成标准化模型价格数据；至少覆盖公开接口中的模型名、输入价和输出价，并保留缓存/分组字段。Linux.do Marketplace 预置可见且明确显示“匿名价格接口尚未确认，暂不可采集”，不猜测 endpoint、不携带认证信息。
- [ ] dashboard 默认显示付费中转站；点击二态控件切换到公益站后，列表只包含公益比较组，并能按站点查看同一公益站的多模型价格。
- [ ] 公益站行不显示官方价格对比或付费站推荐差异，页面明确提示价格单位/比例为站点积分或额度，默认比例为 `1:1`。
- [ ] 在付费/公益模式间切换、刷新数据、重新打开 dashboard 后，筛选结果、空状态、汇总和行数据保持与当前模式一致。
- [ ] 公益站请求不携带认证凭证；接口失败时显示站点级错误，不影响付费站模式使用。
- [ ] 现有付费站抓取、官方价格对比、站点筛选和旧配置迁移测试继续通过；新增适配和切换逻辑有对应单元测试。
- [ ] UI 通过键盘与基础无障碍检查，窄屏不出现横向滚动，切换反馈清晰且尊重 `prefers-reduced-motion`。

## Out of scope

- 不实现公益站自动签到、登录、自动领取积分或代用户操作账户。
- 不把公益站积分换算成人民币，也不基于 `1:1` 生成「省钱百分比」或付费站推荐分。
- 不把 Linux.do Marketplace 或 WindHub 拆成多个用户可配置站点。
- 不重做整个 dashboard 视觉系统，不引入新的前端框架或依赖。
- 不修改付费站现有数据源、官方价格源和推荐排序规则，除非为隔离公益比较组所必需。
