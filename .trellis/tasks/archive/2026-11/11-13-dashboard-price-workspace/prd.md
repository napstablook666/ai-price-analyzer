# 扩大模型价格展示区并添加交替行色

## Goal

让价格表占据仪表盘主要视口，并按模型添加交替底色以区分相邻报价

## Requirements

- 桌面端将签到和筛选排序放入右侧栏，价格明细占据剩余宽度与主要高度；上方仅保留标题、模式切换和紧凑统计摘要。
- 1440×900 时表格滚动区域目标高度至少 600px，1280×720 时至少 400px；表格内部滚动，不让 body 增长。
- 1100px 以下恢复纵向布局与卡片式报价，保留既有局部滚动和触控行为。
- 按当前页 `canonicalModel` 首次出现顺序分配 `model-band-even/odd`；同一模型的多条报价同色，相邻不同模型交替使用白色与既有浅灰 token。
- 保留所有现有 ID、筛选、刷新、签到、JEV、折叠和分页行为，不改变价格数据或排序规则。

## Acceptance Criteria

- [x] 1440×900 与 1280×720 实测表格高度达到目标，签到和全部筛选仍可用，body 无溢出。
- [x] 浏览器确认同一模型多行同色，相邻不同模型底色交替，hover 与窄屏卡片仍清楚。
- [x] 新增模型色带分配单元测试，并通过全部扩展测试、`node --check` 和 `git diff --check`。
- [x] 保存桌面与窄屏截图和测量结果，确认未用隐藏功能换取展示空间。
