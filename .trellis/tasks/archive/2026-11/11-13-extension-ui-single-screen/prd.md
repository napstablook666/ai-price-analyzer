# 三页单屏重构与站点插件化

## Goal

参考 `yetone/magpie` 的实际界面，重构 `popup.html`、`dashboard.html`、`options.html`，按功能分区并控制在一屏内；把中转站点拆为扩展内置、按需加载的本地插件，支持多选后一键添加。

## Requirements

### 界面与交互

- 三页统一使用 Magpie 式浅灰画布、白色内容面板、细分隔线、紧凑列表与顶部导航；保留本项目品牌，不复制 Magpie 品牌内容。
- `dashboard.html` 按标题与模式、统计摘要、签到、筛选排序、价格明细分区；表格与分页在剩余视口内局部滚动，签到、刷新预检和进度继续可用。
- `options.html` 分为“站点与插件”“模型服务”“偏好与成本”“数据与工作区”四个 hash 直达视图，保留 Agent 添加、LLM/JEV、成本估算、工作区和导入导出入口。
- `popup.html` 分为“查看与刷新”“当前页面”“站点服务”，尺寸不超过 360×600；状态较长时在状态区域内部滚动。
- 完整页使用 `100dvh` 应用骨架；表格、插件目录和当前设置分区内部滚动，不让 body 随内容无限增长。
- 保留现有业务元素 ID、`data-*` 和消息行为；布局隐藏仅用于切换分区，不卸载或裁掉必要功能。

### 本地站点插件

- 每个中转站点拥有独立的本地 ES 模块，封装站点预设、host/path 匹配、prepare 与 request 策略；公共采集和解析器继续复用核心模块。
- 轻量目录只暴露插件 ID、名称、host、分类、采集模式、认证说明等展示元数据；站点模块通过静态白名单中的 `import()` 按需加载，不允许远程或用户提供的代码。
- 已添加状态由现有站点数据派生，不维护第二份安装清单。已有站点通过 `pluginId` 或 host 匹配自动迁移为已添加插件。
- 新安装不再自动添加全部中转站或公益站。打开仪表盘只同步已添加站点对应的模块；显式分析/测试一个已知站点时可单独加载其模块。
- 插件目录支持搜索、分类筛选、多选未添加项和“一键添加”；重复添加幂等，批量操作只提交一次合并后的站点列表。
- 自定义站点与 Agent 添加流程继续可用，未知 host 仍走现有通用适配。
- 站点删除后从运行时注册表移除；浏览器自身 ES 模块缓存不视为活跃插件注册。

## Constraints

- Manifest V3、原生 HTML/CSS/JavaScript；不引入框架、远程脚本、远程字体或外链图标。
- 不改写采集响应格式、签到、JEV 匹配、凭据存储和价格计算算法。
- 不覆盖当前工作区已有的未提交业务修改；先保存相关基线 diff，再做最小范围编辑。
- 图标按钮必须有可访问名称；选择、焦点、弹层和状态反馈可键盘操作。

## Acceptance Criteria

- [x] 三页采用一致的顶部导航与视觉 token，功能分区和主次操作清楚，风格与 Magpie 参考截图一致但不复制其品牌。
- [x] dashboard/options 在 1440×900 与 1280×720 下无 body 级纵向滚动；360px 宽下无横向页面溢出，所需内容可通过明确的局部滚动或分页到达。
- [x] popup 在 360×600 内完整展示主要操作，无 body 级滚动；长状态不挤压主要操作。
- [x] 插件目录可搜索、筛选、多选并一键添加；已添加项和重复提交不会生成重复站点。
- [x] 空数据启动不加载全部站点模块；已有站点可自动恢复；显式分析已知站点只加载匹配模块。
- [x] 原有刷新预检、刷新、签到、筛选分页、站点增删改、模型配置、工作区和导入导出仍可用。
- [x] 所有交互控件有可见焦点和 accessible name；正文对比度至少 4.5:1；dialog 打开/关闭及视图切换有合理焦点管理。
- [x] 新增插件加载/批量添加测试，并通过现有扩展测试、相关 `node --check` 和 `git diff --check`。
- [x] 用浏览器实测三页桌面/窄屏布局及一次多选添加流程，记录实际视口和结果。
