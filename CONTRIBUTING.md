# Contributing

Thanks for helping improve AI Price Analyzer.

## Before opening a pull request

- Run `node --check "AI中转站价格分析工具.js"`.
- Run `node test-kbq-pricing.js`.
- Remove credentials, cookies, authorization headers, private URLs, and account identifiers from examples, logs, and screenshots.
- Describe the target page pattern and provide only a sanitized response structure.
- Keep changes focused on the userscript, tests, documentation, or release automation.

## Pull requests

Explain the user-visible behavior, the pages affected, and how you tested the change. Changes to host permissions or cross-origin requests should include a short reason and update `PRIVACY.md` when relevant.
