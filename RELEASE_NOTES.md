# AI Price Analyzer

The following release notes summarize the first public release.

## Added

- Browser userscript for comparing gateway model prices.
- OpenRouter model reference data and Bank of China exchange-rate lookup.

- CI checks and tag-driven GitHub Release packaging.

## Privacy review

The release source was checked for common credential and private-key markers. No credentials are intentionally included. Review the repository and release assets before distributing site-specific pricing samples.
