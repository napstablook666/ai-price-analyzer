# Security Policy

## Supported versions

Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Do not disclose credentials, private response data, or an exploitable issue in a public issue. Use GitHub's private vulnerability reporting for this repository when available. If it is not enabled, contact the repository owner through the private contact method shown on the GitHub profile and include:

- a short description of the issue;
- affected version or commit;
- safe reproduction steps;
- the possible impact.

Please allow time for triage before publishing details.
