# 配置总览 ⚙️

扩展的设置分三层：

```
站点配置      →  每个站怎么采、怎么计价
偏好与成本    →  全局怎么算、怎么排、显示什么
```

改完任何一层，回到比价面板点「刷新全部」看效果。

## 三层各管什么

| 层 | 管什么 | 存在哪 | 文档 |
| --- | --- | --- | --- |
| 站点配置 | 地址、认证、采集适配器、充值比例、价格口径、标签 | 本地存储，可导出 | [站点字段](./station-fields) |
| 偏好与成本 | 货币汇率、比价视图、推荐口径、月用量、匹配规则 | 同上 | [偏好与成本](./settings) |

## 改配置的安全顺序

1. 先记下改前的值，方便回滚。
2. 一次只改一类：要么改站点字段，要么改偏好。
3. 改完看一个已知站点的数字有没有变。
4. 数字不对就回滚，别在错的基础上继续调。

## 最常改的四件事

| 想做的事 | 去哪 |
| --- | --- |
| 加一个站 | 站点与设置 → 站点插件 → 添加站点 |
| 成本算得不对 | 站点字段里的 `priceCurrency` 和充值比例 |
| 表里行数太少 | 偏好 → 匹配规则，或加人工覆盖 |
| 换电脑 | 重新配置站点与凭据 |

## 配置错了会怎样

扩展不做破坏性操作。配置错的后果只有三种：

- 采不到数据（地址、认证、适配器错）。
- 数字算错（价格口径、充值比例、汇率错）。
- 行合并错（匹配规则过宽）。

三种都能靠改配置修复，不需要重装。
