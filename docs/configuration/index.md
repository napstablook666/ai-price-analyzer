# 配置总览 ⚙️

设置都在「站点与设置」页（`options.html`，面板顶栏「设置」也能进去），左侧边栏分四块：

```
已安装      →  本站装了哪些插件、加了哪些站点
插件仓库    →  浏览、安装、更新、移除插件
偏好与成本  →  成本口径、匹配规则、AI 辅助判定
关于        →  版本与更新、链接与许可、本地数据
```

改动即时生效：表单没有「保存」按钮，输入停下就自动写入，切走或关掉页面时补存一次。保存失败会弹红色提示。回到比价面板时面板会重拉数据，不用重新采集。

## 每块管什么

| 区域 | 管什么 | 文档 |
| --- | --- | --- |
| 已安装 | 站点清单、站点开关、充值比例与价格口径、采集适配器、标签 | [站点字段](./station-fields) |
| 插件仓库 | 站点插件与签到插件的来源、安装、批量安装、自动更新 | [站点与插件](../guide/stations) |
| 偏好与成本 | 成本口径与月用量、汇率、匹配规则、AI 辅助（模型服务 / 判定队列） | [偏好与成本](./settings)、[模型匹配](./matching) |
| 关于 | 版本、更新检测、许可、本地存储用量 | — |

站点、报价快照和设置在 `chrome.storage.local`；模型服务的密钥只进会话存储，浏览器重启后需要重新填。

## 改配置的安全顺序

1. 先记下改前的值，方便回滚。
2. 一次只改一类：要么改站点字段，要么改偏好。
3. 改完看一个已知站点的数字有没有变。
4. 数字不对就回滚，别在错的基础上继续调。

## 最常改的四件事

| 想做的事 | 去哪 |
| --- | --- |
| 加一个站 | 插件仓库装站点插件 → 已安装 → 添加中转站 |
| 成本算得不对 | 偏好与成本 → 成本估算设置（月用量预设），再检查站点的 `priceCurrency` 和充值比例 |
| 表里行数太少 | 偏好与成本 → 模型匹配规则，或加人工覆盖 |
| 模型没匹配上 | 判定队列里跑一次 AI 辅助识别，或手工补覆盖 |

## 配置错了会怎样

扩展不做破坏性操作。配置错的后果只有三种：

- 采不到数据（地址、认证、适配器错）。
- 数字算错（价格口径、充值比例、汇率错）。
- 行合并错（匹配规则过宽）。

三种都能靠改配置修复，不需要重装。
