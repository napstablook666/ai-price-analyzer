# 免责声明 ⚖️

扩展给出的价格、月成本、价差和推荐结论都是估算值，仅供参考，以站点后台的实际扣费为准。

## 每个数字怎么来的

| 输出 | 依据 | 容易错在哪 |
| --- | --- | --- |
| 站点单位价 | 抓取那一刻站点页面或接口返回的价目 | 站点改价、分组倍率不同、登录态看到的档位不一样 |
| 折算价格 | 站点单位价 × 充值比例，美元价再乘汇率 | 充值比例填错、汇率过期、币种没核实 |
| 月成本 | 折算价格 × 你在「偏好与成本」里填的月用量 | 用量是一组假设，和你的真实账单无关 |
| 价差、混合单价 | 本站月成本对比同模型基准月成本 | 基准价本身也是参考站公开价，和各家中转的实际源头价有出入 |

## 哪些数字误差最大

- 带 `≈` 前缀或「估算」小字的单元格：价格从别的档位推出来（`evidence: "estimated"`），或者来源只是一次人工核对。
- 标「币种待核验」的站点：币种没在配置里确认，整列折算会一起偏移。
- 按次、按张、按像素的报价：要先折算成元/1M 或元/张，折算分母来自站点画像或估算的单次 token。
- 公益站和未核验站点：价格可能缺失、过期，或者按不可比处理，这些行不参与推荐。
- 快照很旧的行：站点早就改过价，扩展还拿着上一次抓到的数。

## 使用边界

- 扩展不核对账单、不代下单、不代表任何站点的官方口径。
- 站点币种、充值比例、套餐档位、汇率任意一项变化，整列数字都会跟着变。改完重算一遍再看结论。
- 站点随时可以改价、调整计费规则、限流或断开采集入口，扩展手上的只是抓取那一刻的数据。
- 依据扩展的数字做出的充值、采购、迁移决定，风险由使用者承担。
- 自动化采集是否被站点允许由站点自己的条款决定，遵守条款是使用者的责任，见[会不会封号](./faq)。
