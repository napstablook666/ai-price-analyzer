# 成本与推荐 💰

只看单价会选错站。贵的站可能缓存便宜，便宜的站可能输出价高。这一节讲清楚扩展怎么把单价折成月账单，以及推荐分怎么算。

## 两种价格形态

每条报价有两个量：

- **计价单位价格**：站点自己的「中转币 / M token」，分输入、缓存读取、缓存写入、输出、图片等档位。
- **折算价格**：把站点单位换算成人民币后，和官方美元价放到同一把尺子上。

充值比例决定换算系数：

```
每 1 中转币成本（¥） = 充值金额（¥） ÷ 到账中转币
```

站点按美元标注基础价时，扩展用汇率把 `USD / 1M` 转成中转币口径，再参与比较。站点配置里的「基础价 / 1M USD」和「币种已核实」就是给这一步用的。

## 月用量

「偏好与成本」里的月用量决定账单规模，界面上有 10 个输入框，外加一个预设选择：

| 字段 | 界面单位 | 说明 |
| --- | --- | --- |
| 输入 | M tokens | 每月输入 token |
| 缓存读取 | M tokens | 命中缓存的输入 token |
| 缓存写入 | M tokens | 写入缓存的 token |
| 缓存写入（1h） | M tokens | 1 小时保留期的缓存写入 |
| 输出 | M tokens | 每月输出 token |
| 请求次数 | 次 | 按次计价的站点用它 |
| 高峰占比 | % | 高峰/低峰档位按这个比例拆用量 |
| 图像输入 | M tokens | 图片模型输入量 |
| 图像输出 | M tokens | 图片模型输出量 |
| 图像请求数 | 次 | 图片请求次数 |

界面上填的是百万 token，存进设置时乘回 `1,000,000`，所以内部是 token 原值。

五种取值方式（`usage-preset`）：

- **实测月用量**：默认值，取自实测数据（输入 382.95M、缓存读取 2946.28M、输出 30.74M），高峰占比 7/24。
- **magpie-30天 / magpie-7天**：用 magpie 记的最近 30 天 / 7 天用量折算，比手填更贴近实际消耗。
- **基础估算**：3000 万输入 / 600 万输出，其余为 0。
- **自定义**：任意字段一改，预设会自动变成「自定义」，旧值保留。

## 月成本怎么算

对每个参与计价的档位：

```
档位成本 = 用量（token） × 该档单价（每 M token） ÷ 1,000,000
月成本 = Σ 档位成本 + 按次计费 + 图片成本
```

站点的档位名不完全一致，扩展按语义对齐：`input`、`cache_read`、`cache_write`、`output`、`image` 等，缺失的档位按 0 计，不做猜补。

改完用量保存后，切回面板就按新值重排（面板在页面重新可见时重载）。成本是本地折算，不触发重新采集。

## 相对官方

```
相对官方 = 该站月成本 ÷ 同模型官方月成本
```

- `0.35×` 表示官方价的三五折。
- `1.00×` 表示和官方持平。
- 没有对上官方价的模型不显示倍数，只在「显示未匹配」打开时进表。

官方月成本用的是同一套用量，所以倍数只反映价格差异，不掺用量假设。

## 推荐分

推荐分是「成本 + 证据」的加权结果，三种口径：

| 口径 | 成本权重 | 证据权重 | 适合 |
| --- | --- | --- | --- |
| 均衡推荐 | 80% | 20% | 成本和可信度都要 |
| 价格优先（默认） | 90% | 10% | 只看钱 |
| 稳定优先 | 70% | 30% | 更在意数据可信度 |

「证据」来自匹配置信度、价格口径是否已核实、快照是否新鲜、采集是否成功。证据弱的行即使便宜，推荐分也不会高。

推荐分是排序用的相对指标，不是绝对评分，不跨口径比较。

## 状态标签

报价行的状态决定它能不能进「相对官方」的比较，也决定推荐分的高低：

| 标签 | 含义 | 影响 |
| --- | --- | --- |
| 已校准 | 币种、档位、官方价都对上了 | 正常参与排序与推荐 |
| 币种待核验 | 站点价格币种没在配置里确认 | 折算打折扣，推荐分降低 |
| 缺少 1 小时缓存价 | 站点没有 1h 缓存写入档位 | 该档按 0 计，不影响其他档 |
| 中转价格未收录 | 站点返回里没有这一档 | 该档按 0 计 |
| 未匹配 | 没对上官方价 | 不进「相对官方」排序 |
| 过期 | 快照超出有效窗口 | 默认仍显示，可关闭「显示过期」 |
## 汇率

- 支持人民币与美元两种显示货币。
- 汇率可以手动填，也可以点「从中国银行刷新」拉当日牌价。
- 拉取失败时沿用上一次成功值，并标记日期。
- 汇率变化只影响折算，不改站点原始价格。

## 什么时候该怀疑数字

| 症状 | 先查 |
| --- | --- |
| 月成本比站点标价高一个数量级 | 单位是每 M token 还是每 K token |
| 相对官方恒等于 1 | 官方价没加载，模型被当成未匹配或直接回落 |
| 数字是 0 | 该档位没在站点返回里，或用量字段为 0 |
| 同一模型两行倍数差很多 | 分组或模型写法不同，匹配置信度低 |
