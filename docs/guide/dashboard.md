# 价格对比 📊

价格对比面板是主界面。它把站点快照、基准参考价、汇率和你的用量口径拼成一张表：一行是「一个站点 + 一个分组 + 一个模型」的报价。

文中「基准」指 OpenRouter 的公开模型价，比价时作为参照价。扩展从 `openrouter.ai` 拉一份模型清单，按汇率折成人民币，与站点报价同口径并列显示。

## 顶部

| 元素 | 作用 |
| --- | --- |
| MODEL ATLAS · 价格对比 | 站点名与页面标题 |
| 状态点 + 合并读数 | 付费模式：`更新于 hh:mm:ss · 基准价 N HH:MM`，前面是当前模式最新快照采集时间，后面是基准价缓存模型数与写入时间（时:分）；没有快照显示「尚未刷新」，基准价没加载过显示「基准价未加载」。公益模式只显示快照时间。悬停基准价段可查看告警与缓存口径 |
| 比较来源 | `付费中转站` 和 `公益站` 两个按钮，两种模式各自独立刷新、独立比价，切换不会丢数据 |
| 刷新指定站点 | 下拉里勾选要采的站点（带站点搜索、`选择当前结果`、`清空`），点 `刷新已选站点` 只采这些站点，不走预检 |
| 刷新全部 | 触发预检与采集，见[采集价格](./collection) |
| 折叠全部 / 展开全部 | 同一个按钮，按当前状态整体切换，文案和图标跟着变 |
| 每日签到 | 下拉面板：`签到站点`、`刷新状态` 和站点状态列表；没装签到插件时给一个「去插件仓库」入口。详见[每日签到](./checkin) |
| 设置 | 就地拉出设置面板，默认落在「已安装」，也可以直接进 `options.html#installed` |
| 主题 | 白天 / 夜晚切换 |

## 预检面板

点过「刷新全部」之后，页面上方出现「页面登录状态」面板：

- 首行状态文字说明当前分组有几个启用站点。
- 下面列出每个站点的预检结果与原因，结果分四类：`已登录`、`需要登录`、`需人工确认`、`无需登录`。
- 两个按钮：`取消` 和 `确认开始刷新全部`。确认才真正采集。

## 采集进度

采集开始后出现「采集进度」：进度条、`N / M 站点`、当前在采的站点，以及每站的成败列表。进度靠 `REFRESH_PROGRESS` 消息推送，不是定时轮询；service worker 被回收就停住。
采集完成后面板再留 5 秒展示汇总和每站结果，然后自动收起；下一轮刷新开始会重新展开。出错时面板保持可见。

## 摘要条

页头是一条紧凑摘要：四组「标签 数值」胶囊，右侧是当前筛选后的报价条数，明细说明放进悬停提示。

| 付费模式 | 公益模式 |
| --- | --- |
| 覆盖模型：去重后的模型数 | 公益模型：模型数 |
| 基准匹配：有基准参考价的条数 | 公益站点：站点数 |
| 首选方案：被标成推荐的报价条数 | 价格单位：站点积分 / 额度，首版按 1:1 展示 |
| 需核验：未匹配、推导、部分解析、价格缺失的总数 | 数据状态：需核验条数 |

悬停「需核验」胶囊可以看拆分明细，比如「3 条部分解析」。

## 月成本与混合单价

价格明细表把月成本、价差、混合单价放在同一格：

- 「月成本 · 混合单价」一列里，第一行是月成本金额和 `低 x%` / `高 x%` / `持平`（算不出时显示具体原因），第二行是 `混合 ¥x /M`。名次不常驻，在单价单元格底部那根月成本长条上停住约 2 秒才看排名。
- 合并后付费模式是五列：模型、中转站、单价（费用项 / 基准 / 中转）、月成本 · 混合单价、状态（公益站用）。
- 月成本长条在「单价」单元格底部，按同一规范模型在完整筛选结果中的最高月成本满格，柱长为 `当前月成本 ÷ 同模型最高月成本 × 100%`，不随分页跳动，也不提供跨模型的全局标尺。
- 浮层只挂在长条上：月成本金额只是文字，鼠标扫过去不会弹东西。要在这根长条上停住约 2 秒才会浮现（划过、走开都会取消），点一下则立刻打开；浮层显示当前报价在同模型里的完整月成本排名（同模型有多少条报价就列多少条，不截断），浮现时自动把当前这条滚到列表中部；列表里当前这一条带浅色底、左侧色条和「当前」胶囊。浮层挂在页面固定层里，鼠标移进去可以滚动列表，不会因为移出单元格而关掉，离开浮层、点外部或按 Esc 才收。
- 名次是列表里的先后次序（同价也按先后排 #1、#2，不并列）。点浮层里任意一条，会翻到这条报价所在的页、把那一行滚到视野中间并连闪两下，方便对上表格里的位置。
- 单元格只显示真实月成本金额。不同模型的月成本可以直接比金额，长条只用于同模型相对比较。
- 只画付费中转站，公益站整列隐藏。价格缺失或用量口径算不出对应数值时显示原因，不伪造柱长。

## 筛选与排序栏

侧栏是「筛选和排序」：

| 控件 | 作用 |
| --- | --- |
| 搜索框 | 同时匹配模型写法、站点名、供应商 |
| 全部中转站 | 单站点筛选，里面还有搜索框；站点名后面挂 `×0.62` 这类折扣中位数，样本不足 3 个模型不显示 |
| 供应商 | 多选，带「全选 / 清空 / 常用」和搜索；默认全选，改过的勾选自动存进 `localStorage` 的 `model-atlas:provider-filter`（JSON 数组），刷新页面和切模式后沿用，勾满或点「全选」等于清掉记忆 |
| 常用 | 供应商栏里的单按钮，点开是小浮层：「套用常用」回填手动存下的名单，「设为常用」把当前勾选存成新名单，chip 上的 `×` 从名单里剔掉单个供应商。名单单独存在 `model-atlas:provider-favorite`，跟上面那份自动记忆互不覆盖；套用时按当前有报价的供应商取交集，一个都不剩就回到全选 |
| 分组 | 多选，带「全选 / 清空」和搜索 |
| 排序方式 | 分组、供应商、模型名称、月成本、混合单价（默认）、价差、匹配置信度 |
| 排序方向 | 升序（默认）/ 降序 |
| 次级排序 | 价差（默认）、模型名称、月成本、匹配置信度、不使用 |
| 更新基准价 | 手动刷新基准参考价与汇率 |
| 重置 | 清掉全部筛选与排序条件 |
| 模型对比 | 固定展开、不折叠；默认 4 个输入框，框数记在 `localStorage` 的 `model-atlas:model-filter-boxes`，刷新后保留；底部「添加筛选框」增加一个（上限 24），其右侧 × 移除最后一个，新增框自带 × 单独移除前四个以外的任意框；按模型逐个填值筛选 |
| 显示未匹配 | 勾上后，没有基准参考价的模型也进表 |

`供应商`、月成本、混合单价、价差这几项在公益模式下不适用，相关按钮与列由 `paid-only` 类隐藏。

## 价格明细表

明细表没有独立标题行，表头直接顶到面板边。想立刻换一份基准价就点侧栏「更新基准价」，当前基准价状态看顶栏合并读数。

### 列

| 列 | 内容 |
| --- | --- |
| 模型 | 模型名 +（付费模式下）供应商标签；下方只显示匹配置信度百分比，悬停或点击可查看基准主候选、匹配规则与全部候选；鼠标离开详情或点击外部会关闭浮窗；未匹配显示 `0%` |
| 中转站 | 站点名（可点，在新标签打开该站首页，悬停出现外链图标；按站点筛选走右侧「全部中转站」）、分组名，有分组倍率时追加 `×N` |
| 单价 | 费用项、基准、中转三小列，表头 `费用项` 旁的 ℹ 按钮说明单位口径；行首是输入 / 输出 / 缓存读 / 缓存写等费用项，基准与中转同口径并排，缺值显示 `—`；中转列逐项和基准比大小上色，比基准贵标红 `▲`、便宜标绿 `▼`，差距在 0.5% 以内、基准缺价或任一侧是估算值时保持中性灰（悬停可看具体差多少百分比），基准列永远是中性基准色；单元格底部是同模型月成本长条 |
| 月成本 · 混合单价 | 第一行：月成本金额（在单价单元格底部的月成本长条上停住约 2 秒可看同模型全部月成本排名并自动定位到当前这条，名次只在浮层里出现）+ 价差标签；第二行：`混合 ¥x /M`（月成本 ÷ 计费 token 总量，标注混合配比；公益站不输出）。价差配色：低于基准40% 以上绿色、低 2–40% 蓝色、接近基准黄色、高于基准50% 以上红色 |
| 状态 | 公益模式下单独一列，只放状态标签 |

推荐状态仍由 `core/pricing.js` 计算，用于「首选方案」统计卡；价格明细表不单独展示「推荐」列。

评级分类用于价格柱和行状态：`excellent` / `good` 绿或蓝，`fair` 黄，`bad` 红。

状态标签（`statusMarkup`，公益模式的状态列）：

| 标签 | 什么时候出现 |
| --- | --- |
| `价格推导` | 价格是从别的档位推算出来的（`evidence === "estimated"`） |
| `部分解析…` | 快照是 partial，后面会跟未解析的计费方式、异常价格字段、未定价模型 |
| `币种待核验` / `缺少 1 小时缓存价` / `中转价格未收录` | 价格缺失的具体原因 |

标签都不成立时这一列留空。付费模式下判断有没有基准参考价，看「基准匹配」胶囊和模型列的置信度。

### 按张计费

主表只放按 token 计价的报价。站点只报了「多少钱一张图」、没有任何 token 价的模型，会出现在表格下方的「按张计费」折叠块里：

| 列 | 说明 |
| --- | --- |
| 站内价 / 张 | 站点报的元/张，已按站点币种和充值比例折算 |
| 基准价 / 张 | OpenRouter 的 `pricing.image`（美元/张）按汇率折成人民币 |
| 对比基准 | 站内价相对基准价的百分比，比基准低显示绿色 |
| 月成本 | 元/张 × 你在「偏好与成本 → 估算月用量」里填的图像请求数；没填就提示去填，不显示 0 |

这类报价不进月成本排名、不参与推荐，因为它们的 token 成本恒为 0，混进按 token 的比较会得出「低 100%」这种假结论。

### 行数、分页与滚动

- 摘要条右侧的 `N 条报价` 是筛选后的条数。
- 分页每页可选 20（默认）、50、100、200、500 条，带上一页 / 下一页。
- 页码显示成「第 [1] / 59 页」，中间的页号本身就是输入框，没有单独的「跳至」框。聚焦即全选，填目标页号后回车、失焦或点其它地方都按一次提交跳转；超出总页数按最后一页处理，小于 1 按第一页处理，清空或填非数字留在原页，`Esc` 放弃输入。
- 表格可横向滚动，宽度不够时按列读。

### 空状态

没数据时表面换成一句提示，文案随情况变：没加站点、加了但没采集、公益模式下没有公益站。

## 刷新之后该看什么

1. 先看摘要条的「需核验」，它是所有可疑行数的汇总。
2. 再看状态标签，按 `价格推导` → `部分解析` 的顺序处理。
3. 月成本不合预期时，去[成本与推荐](./cost)核对用量与计价口径，而不是怀疑采集。
