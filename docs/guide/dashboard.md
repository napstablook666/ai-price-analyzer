# 价格对比 📊

价格对比面板是主界面。它把站点快照、官方参考价、汇率和你的用量口径拼成一张表：一行是「一个站点 + 一个分组 + 一个模型」的报价。

## 顶部

| 元素 | 作用 |
| --- | --- |
| MODEL ATLAS · 价格对比 | 站点名与页面标题 |
| 状态点 + 合并读数 | 付费模式：`更新于 hh:mm:ss · 官方价 N HH:MM`，前面是当前模式最新快照采集时间，后面是官方价缓存模型数与写入时间（时:分）；没有快照显示「尚未刷新」，官方价没加载过显示「官方价未加载」。公益模式只显示快照时间。悬停官方价段可查看告警与缓存口径 |
| 站点与设置 | 就地拉出设置面板，默认落在「已安装」，也可以直接进 `options.html#installed` |
| 菜单 | 一个下拉：折叠/展开全部、刷新当前站点、每日签到（装了签到插件才出现） |
| 折叠全部 / 展开全部 | 同一个按钮，按当前状态整体切换，文案和图标跟着变 |
| 刷新全部 | 触发预检与采集，见[采集价格](./collection) |
| 刷新当前站点 | 站点筛选选中某站后才可点，只采这一站，不走预检；菜单里也有一份 |

标题下面一排是**比较来源**：`付费中转站` 和 `公益站`，两种模式各自独立刷新、独立比价，切换不会丢数据。

## 预检面板

点过「刷新全部」之后，页面上方出现「页面登录状态」面板：

- 首行状态文字说明当前分组有几个启用站点。
- 下面列出每个站点的预检结果与原因。
- 两个按钮：`取消` 和 `确认开始刷新全部`。确认才真正采集。

## 采集进度

采集开始后出现「采集进度」：进度条、`N / M 站点`、当前在采的站点，以及每站的成败列表。进度靠 `REFRESH_PROGRESS` 消息推送，不是定时轮询；service worker 被回收就停住。

## 摘要条

页头不再有「MODEL EXPLORER / 模型报价」标题块，只留一条紧凑摘要：四组「标签 数值」胶囊，右侧是当前筛选后的报价条数，明细说明放进悬停提示。

| 付费模式 | 公益模式 |
| --- | --- |
| 覆盖模型：去重后的模型数 | 公益模型：模型数 |
| 官方匹配：有官方参考价的条数 | 公益站点：站点数 |
| 首选方案：被标成推荐的报价条数 | 价格单位：站点积分 / 额度，首版按 1:1 展示 |
| 需核验：未匹配、推导、部分解析、价格缺失的总数 | 数据状态：需核验条数 |

## 月成本与混合单价

价格明细表把月成本、价差、混合单价并成一格：

- 「月成本 · 混合单价」一列里，第一行是月成本金额和 `低 x%` / `高 x%` / `持平`（或具体原因），第二行是 `混合 ¥x /M`。名次不常驻，悬停或点击金额才看排名。
- 合并后付费模式只剩五列：模型、中转站、单价（费用项 / 官方 / 中转）、月成本 · 混合单价、状态（公益站用），列宽 24% / 20% / 9% + 13% + 13% / 21%。

- 月成本长条移到「单价」单元格底部，按同一规范模型在完整筛选结果中的最高月成本满格，柱长为 `当前月成本 ÷ 同模型最高月成本 × 100%`，不随分页跳动，也不提供跨模型的全局标尺。
- 悬停或点击长条、月成本金额，浮层显示当前报价在同模型里的月成本排名和最低的前 10 条报价；浮层挂在页面固定层里，鼠标移进去可以滚动列表，不会因为移出单元格而关掉，离开浮层、点外部或按 Esc 才收。
- 单元格只显示真实月成本金额，不再显示「月省」「月多付」；不同模型的月成本可直接比较金额，但长条只用于同模型相对比较。
- 只画付费中转站，公益站沿用整列隐藏。价格缺失或用量口径算不出对应数值时显示原因，不伪造柱长。
## 筛选与排序栏

侧栏第一块是「筛选和排序」：

| 控件 | 作用 |
| --- | --- |
| 搜索框 | 同时匹配模型写法、站点名、供应商 |
| 全部中转站 | 单站点筛选，里面还有搜索框；站点名后面挂 `×0.62` 这类折扣中位数，样本不足 3 个模型不显示 |
| 供应商 | 多选，带「全选 / 清空」和搜索 |
| 分组 | 多选，带「全选 / 清空」和搜索 |
| 排序方式 | 分组、官方源、模型名称、月成本、混合单价（默认）、价差、匹配置信度 |
| 排序方向 | 升序（默认）/ 降序 |
| 次级排序 | 价差（默认）、模型名称、月成本、匹配置信度、不使用 |
| 更新官方价 | 手动刷新官方参考价与汇率 |
| 重置 | 清掉全部筛选与排序条件 |
| 模型对比 | 固定展开、不折叠；默认 4 个输入框，框数记在 `localStorage` 的 `model-atlas:model-filter-boxes`，刷新后保留；底部「添加筛选框」增加一个（上限 24），其右侧 × 移除最后一个，新增框自带 × 单独移除前四个以外的任意框；按模型逐个填值筛选 |
| 显示未匹配 | 勾上后，没有官方参考价的模型也进表 |

`官方源`、月成本、混合单价、价差这几项在公益模式下不适用，相关按钮与列由 `paid-only` 类隐藏。

## 价格明细表
明细表没有独立标题行，表头直接顶到面板边。官方价状态胶囊已并入顶栏合并读数（见「顶部」），想立刻换一份就点侧栏「更新官方价」。

### 列

| 列 | 内容 |
| --- | --- |
| 模型 | 模型名 +（付费模式下）供应商标签；下方只显示匹配置信度百分比，悬停或点击可查看官方主候选、匹配规则与全部候选；鼠标离开详情或点击外部会关闭浮窗；未匹配显示 `0%` |
| 中转站 | 站点名（可点，点了就按该站筛选）、站点类别（付费中转站 / 公益站）、分组名、`tier · 倍率 ×N` |
| 单价 | 费用项、官方、中转三小列，不再有「单价 / 每 M tokens」分组表头；口径都是站点中转币，只显示数值不带 `CR` 前缀，列头信息图标悬停或点击可看单位说明；单元格底部是同模型月成本长条 |
| 月成本 · 混合单价 | 第一行：月成本金额（悬停或点击可看同模型月成本最低前 10 条，名次只在浮层里出现）+ 价差标签；第二行：`低 x%` / `高 x%` / `持平`（无官方价时显示具体原因，低于官方 40% 以上绿色、低 2–40% 蓝色、接近官方黄色、高于官方 50% 以上红色）+ `混合 ¥x /M`（月成本 ÷ 计费 token 总量，标注混合配比；公益站不输出） |
| 状态 | 公益模式下单独一列，只放状态标签 |

推荐状态仍由 `core/pricing.js` 计算，用于「首选方案」统计卡；价格明细表不再单独展示「推荐」列。

评级分类仍用于价格柱和行状态：`excellent` / `good` 绿或蓝，`fair` 黄，`bad` 红。

状态标签（`statusMarkup`，公益模式的状态列）：

| 标签 | 什么时候出现 |
| --- | --- |
| `已校准` | 没有下面任何一条 |
| `未匹配` | 付费模式下没有官方价对应记录 |
| `价格推导` | 价格是从别的档位推算出来的（`evidence === "estimated"`） |
| `部分解析…` | 快照是 partial，后面会跟未解析的计费方式、异常价格字段、未定价模型 |
| `币种待核验` / `缺少 1 小时缓存价` / `中转价格未收录` | 价格缺失的具体原因 |

### 行数、分页与滚动

- 「模型报价」标题右侧显示 `N 条报价`，是筛选后的条数。
- 分页每页可选 20（默认）、50、100、200、500 条，带上一页 / 下一页和页码。
- 表格可横向滚动，宽度不够时按列读。

### 空状态

没数据时表面换成一句提示，文案随情况变：没加站点、加了但没采集、公益模式下没有公益站。

## 每日签到面板

侧栏第二块，只在有可签到站点时出现。详见[每日签到](./checkin)。

## 刷新之后该看什么

1. 先看统计卡的「需核验」，它是所有可疑行数的汇总。
2. 再看状态标签，按 `未匹配` → `部分解析` 的顺序处理。
3. 月成本不合预期时，去[成本与推荐](./cost)核对用量与计价口径，而不是怀疑采集。
