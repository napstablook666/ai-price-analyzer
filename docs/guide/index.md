# 使用指南 🧭

AI Price Analyzer（界面里叫「AI 中转站价格对比」）是一个 Chromium MV3 扩展。它从你配置过的 AI 中转站采集模型价格，把不同站点的模型写法归一到同一个模型身份，再在本地面板里按你的真实用量比较月成本。

一句话版本：**把「这家站便宜」变成「这个模型在你这套用量下每月多少钱」。**

## 它解决什么问题

中转站的价目页各有各的写法：`claude-3.5-sonnet`、`Claude Sonnet 3.5`、`anthropic/claude-3-5-sonnet` 指的是同一个模型，计价单位却在「每 1M token」「每 1K 次调用」「按充值比例折算」之间跳。人工比价有三个绕不过去的坑：

- **模型对不上。** 同一模型在不同站的写法、后缀、供应商前缀都不一样。
- **价格口径对不上。** 有的站标人民币、有的标美元；有的直接标单价，有的要按充值比例换算成中转币。
- **用量对不上。** 单价低不等于月账单低，输入、缓存读取、输出和图片的占比决定最终成本。

扩展把这三件事拆开处理：采集 → 归一 → 按用量折算。采集和归一的结果会落到价格表里，逐行给出官方参考价、月成本、价差和匹配置信度。

## 三个入口

| 入口 | 位置 | 用来做什么 |
| --- | --- | --- |
| 价格对比面板 | 工具栏点扩展图标（已打开就切过去） | 看报价表、混合单价柱、筛选排序、比较来源、进站点设置 |
| 站点与设置页 | 面板右上角「站点与设置」 | 装插件、加站点、改采集配置、调成本口径、调模型匹配 |

两个入口共享同一个 service worker 和同一份存储，关掉面板不会中断采集。

## 上手顺序

1. [安装与加载](./install) — 从 Release 装，或直接加载仓库根目录。
2. [快速开始](./quick-start) — 十分钟内添加第一个站点并看到报价。
3. [站点与插件](./stations) — 添加、启用、批量管理站点。
4. [采集价格](./collection) — 全量刷新、单站点刷新、进度与失败重试。
5. [价格对比](./dashboard) — 筛选、排序、比较来源、看懂每一列。
6. [成本与推荐](./cost) — 把单价折成你自己的月账单。

## 边界

- 只做**读数**：采集站点的公开价目接口或页面，不代下单、不充值、不改站内数据。签到是唯一会触发写操作的功能，且需要你自己在站点设置里勾选。
- 不做**价格预测**：官方价和汇率有缓存周期，表里会标出数据日期。
- 不碰**密钥外传**：站点 Token、API Key 存在扩展的会话存储，导出 JSON 里不含密钥。
