# 官方参考价 🏛️

「相对官方」这一列靠官方价撑着。官方价不是实时抓的，是一份带日期的参考数据，加汇率缓存。

## 数据从哪来

- 官方价按供应商整理：OpenAI、Anthropic、Google、DeepSeek、阿里通义、字节豆包等，单位统一成 `USD / 1M tokens`。
- 每个模型带输入、缓存读、缓存写、输出等档位，图片模型带图片档位。
- 汇率单独缓存，默认取中国银行牌价，取不到就沿用上次成功的值。
- 数据打包在扩展里，首次打开不需要联网就能显示。

## 更新节奏

| 触发 | 行为 |
| --- | --- |
| 面板打开 | 读缓存，不阻塞渲染 |
| 缓存过期 | 提示「更新官方价」，或在刷新时顺带更新 |
| 手动点「更新官方价」 | 强制拉一次，失败保留旧值并提示 |
| 离线 | 用内置快照，标注日期 |

表里显示的官方价带日期。日期旧不一定错，但价格调整后倍数会偏，看到官方调价就手动更新一次。

## 官方价和站点价的对应

官方价只回答一件事：同一个规范模型，官方卖多少钱。它不是「市场均价」，也不包含中转站的折扣。

匹配过程：

1. 站点原始写法 → 规范模型（`claude-sonnet-4` 这类 id）。
2. 规范模型 → 官方价记录。
3. 找不到官方价 → 该行标为未匹配，不参与「相对官方」排序。

匹配细节见[模型匹配](../configuration/matching)。

## 没匹配上怎么办

先看「模型」列的下半部分：

- **空**：完全没有候选，通常是新模型或站点自造名字。
- **灰色 + 低置信度**：按模糊规则对上了，但不确定。
- **红色 / 未匹配**：明确没对上。

处理顺序：

1. 在站点配置里给该模型加别名（插件支持时）。
2. 在「偏好与成本」里放宽匹配规则（后缀、版本号、模糊）。
3. 确认确实没有官方价（私有模型、自建模型），保持未匹配。

## 汇率细节

- 汇率只用于展示与折算，原始价格始终按站点币种保存。
- 手动改汇率后，月成本和倍数立即按新值重算。
- 汇率拉取失败不会把界面卡住，会用缓存值并在提示里标出。
