# 基准参考价 🏛️

「价差」这一列靠基准价撑着。基准价不是实时抓的，是一份带日期的参考数据，加汇率缓存。

## 数据从哪来

- 基准价取自 OpenRouter 的公开模型价，按供应商整理：OpenAI、Anthropic、Google、DeepSeek、阿里通义、字节豆包等，单位统一成 `USD / 1M tokens`。
- 每个模型带输入、缓存读、缓存写、输出等档位，图片模型带图片档位。
- 汇率独立缓存，自动模式每日取 ExchangeRate-API 的 USD/CNY 参考价，主源失败切换 Frankfurter / ECB；界面显示来源与报价日期。
- 数据打包在扩展里，首次打开不需要联网就能显示。

## 更新节奏

| 触发 | 行为 |
| --- | --- |
| 面板打开 | 读缓存，不阻塞渲染 |
| 缓存过期 | 提示「更新基准价」，或在刷新时顺带更新 |
| 手动点「更新基准价」 | 强制拉一次，失败保留旧值并提示 |
| 离线 | 用内置快照，标注日期 |

表里显示的基准价带日期。日期旧不一定错，但价格调整后倍数会偏，看到基准调价就手动更新一次。

## 基准价和站点价的对应

基准价只回答一件事：同一个规范模型，在公开市场上卖多少钱。它不是「市场均价」，也不包含中转站的折扣。

匹配过程：

1. 站点原始写法 → 规范模型（`claude-sonnet-4` 这类 id）。
2. 规范模型 → 基准价记录。
3. 找不到基准价 → 该行标为未匹配，不参与「价差」排序。

匹配细节见[模型匹配](../configuration/matching)。

## 没匹配上怎么办

看「模型」列模型名下方的置信度百分比：

- **`0%`**：没有对应的基准目录记录，通常是新模型或站点自造名字。
- **较低的百分比**：按模糊规则对上了，但不确定；悬停或点击可查看匹配规则和基准候选，鼠标离开详情或点击外部会关闭浮窗。
- **较高的百分比**：匹配依据较明确，仍可在详情里核对主候选与其他候选。

处理顺序：

1. 在「AI 辅助识别 → 判定队列」跑一次「识别当前未匹配」，接受的结果会写成人工确认。
2. 剩下的高频模型在站点配置里加别名，或在「偏好与成本」里放宽匹配规则（后缀、版本号、模糊）。
3. 确认确实没有基准价（私有模型、自建模型），保持未匹配，勾上「显示未匹配」照样能看到这些行。

## 汇率细节

- 汇率只用于展示与折算，原始价格始终按站点币种保存。
- 自动模式直接使用最新参考缓存，不会被历史默认值 `7.3` 覆盖。
- 手动指定后，月成本和折算立即按手动值重算；刷新网络参考不覆盖手动值。
- 汇率拉取失败不会把界面卡住，沿用最后成功值并告警；没有成功缓存时明确标为应急估算。
- 参考价不是支付渠道成交价。站点充值的人民币实付比例以该站充值配置为准。
