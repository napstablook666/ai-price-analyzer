# 快速开始 🚀

照着走一遍，十分钟内你能在价格表里看到第一行报价。

## 1. 装上扩展

从 [Releases](https://github.com/napstablook666/ai-price-analyzer/releases) 下载 `ai-relay-price-extension-v<version>.zip` 解压，或者直接克隆仓库。

打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开「开发者模式」，点「加载已解压的扩展」，选中**直接包含 `manifest.json`** 的那个目录。

细节和常见坑见[安装与加载](./install)。

## 2. 打开价格对比面板

点工具栏里的扩展图标，弹窗里点「打开价格对比」。第一次打开时面板是空的，底部会提示先添加站点。

## 3. 添加第一个站点

在面板右上角点「站点与设置」，进入「站点插件」页。

两种加站方式，任选一种：

- **按网址添加**：点「添加站点」，填站点网址，点「分析站点」。扩展会打开该站页面，试探常见的价目接口和页面结构，把识别到的采集配置填进表单，你确认后保存。
- **从插件里挑**：先在「插件仓库」页签装好需要的站点插件（填地址 → 刷新仓库 → 安装），再到「可选站点」搜索勾选，点「添加所选站点」。插件里已经写死采集规则的站点走这条最省事。

保存前会看到「确认站点配置」，包括采集模式、接口路径、请求方式、认证方式和充值比例。第一次用建议原样保存，跑通后再回来调。

字段逐项解释见[站点配置字段](../configuration/station-fields)。

## 4. 确认登录状态

需要登录才能看到价目的站点，先在弹窗里点「检查登录状态」。扩展会打开站点页面，确认会话是否可用。

- 站点支持 Token 注入：在站点设置的「Token / 密钥」里填一次，之后免登录采集。
- 只支持账号密码：填「用户名 / 密码」，扩展在需要时打开页面走表单登录。
- 站点把登录信息放在 HttpOnly Cookie 里，且没有 Token 入口：只能手动在浏览器里登录一次，采集复用现有会话。

细节见[登录与会话](./session)。

## 5. 刷新采集

回到面板，点右上角「刷新全部」。进度条会显示 `已采 / 总数 站点`。单个站点失败不会中断整轮，失败的站点会标出错误原因并可以单独重刷。

## 6. 读第一张表

报价表默认按「分组」排序。每一行是一个「站点 + 模型 + 分组」的组合，关键列：

- **模型 / 官方匹配**：中转站原始写法在上，规范模型在下。
- **中转币 / M token**：该站自己的计价单位。
- **官方单价**：同一模型在官方 API 的美元价，按当天汇率折算。
- **月成本**：按你在「偏好与成本」里设的月用量估算。
- **相对官方**：月成本除以官方月成本，`0.35×` 就是官方价的三五折。
- **推荐与状态**：推荐分、匹配置信度、是否过期。

## 7. 调成你自己的用量

打开「站点与设置 → 偏好与成本」，先选成本口径预设：

- **实测月用量**：填你自己的输入、缓存读、缓存写、输出、图片和请求量。
- **基础估算**：默认按 3000 万输入 / 600 万输出。
- **自定义**：预设之外，单独覆盖某个字段。

改完回到面板，面板顶部点「刷新全部」重算，月成本列会按新口径重排。
