# 快速开始 🚀

照着走一遍，十分钟内你能在价格表里看到第一行报价。

## 1. 装上扩展

从 [Releases](https://github.com/napstablook666/ai-price-analyzer/releases) 下载 `ai-relay-price-extension-v<version>.zip` 解压，或者直接克隆仓库。

打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开「开发者模式」，点「加载已解压的扩展」，选中**直接包含 `manifest.json`** 的那个目录。

细节和常见坑见[安装与加载](./install)。

## 2. 打开价格对比面板

点工具栏里的扩展图标，直接打开价格对比面板；已经开着就切到那个标签页。第一次打开时面板是空的，中间会提示先添加站点。

## 3. 添加第一个站点

在面板顶栏点「设置」拉出设置页，侧栏里选「插件仓库」或「已安装」。

两种加站方式，任选一种：

- **按网址添加**：点「添加站点」，填站点网址，点「分析站点」。扩展会打开该站页面，试探常见的价目接口和页面结构，把识别到的采集配置填进表单，你确认后保存。
- **从插件里挑**：先在「插件仓库」装好需要的站点插件（填地址 → 刷新仓库 → 安装），再到「已安装」对插件点「添加站点」。插件里已经写死采集规则的站点走这条最省事。

保存前会看到「确认站点配置」，包括采集模式、接口路径、请求方式、认证方式和充值比例。第一次用建议原样保存，跑通后再回来调。

字段逐项解释见[站点配置字段](../configuration/station-fields)。

## 4. 确认登录状态

需要登录才能看到价目的站点，点「刷新全部」时扩展会先做一次登录态预检：能直接用的直接采，需要会话的会列出站点让你先登录，再点一次确认。预检结果分「已登录 / 需要登录 / 需人工确认 / 无需登录」四类。

- 站点支持 Token 注入：在站点设置的「Token / 密钥」里填一次，之后免登录采集。
- 只支持账号密码：填「用户名 / 密码」，扩展在需要时打开页面走表单登录。
- 站点把登录信息放在 HttpOnly Cookie 里，且没有 Token 入口：只能手动在浏览器里登录一次，采集复用现有会话。

细节见[登录与会话](./session)。

## 5. 刷新采集

回到面板，点顶栏「刷新全部」（站点不多时可以先用「刷新指定站点」勾出几家）。进度条显示 `N / M 站点` 和当前在采的站点。单个站点失败不会中断整轮，失败的站点在列表里标出原因，可以再单独重刷。

## 6. 读第一张表

报价表默认按「混合单价」升序。每一行是一个「站点 + 分组 + 模型」的报价，付费模式下是五列：

- **模型**：模型名加供应商标签，下面只保留匹配置信度；悬停或点击百分比可查看基准主候选、匹配规则与全部候选，鼠标离开详情或点击外部会关闭浮窗。
- **中转站**：站点名、分组名，有分组倍率时追加 `×N`；点站点名在新标签打开该站首页。
- **单价**：费用项、基准、中转三小列并排，口径都是中转币，单元格底部是同模型月成本长条。
- **月成本 · 混合单价**：第一行是月成本金额和价差标签，第二行是 `混合 ¥x /M`，模型之间可以直接横着比。
- **状态**：只在公益模式下出现，放 `价格推导`、`部分解析` 这类标签。

价差配色：低于基准40% 以上绿色、低 2–40% 蓝色、接近基准黄色、高于基准50% 以上红色。

## 7. 调成你自己的用量

打开设置页的「偏好与成本 → 成本估算设置」，先选成本口径预设：

- **magpie-30天**：默认预设，按网关最近 30 天用量算月成本，同步后自动更新估算用量。
- **基础估算**：3000 万输入 / 600 万输出，只用来算相对价差。
- **自定义**：预设之外单独填每个字段，共十项，输入、缓存读写、输出、图像、请求数和高峰占比各一个。

30 天用量从本机 magpie 网关自动拉取（默认每 6 小时一次），首次同步前使用内置快照。网关没开时保留上次有效值，不影响扩展其他功能；自定义和基础估算不会被同步覆盖。

改完不用重新采集：设置保存后回到面板，面板会重拉数据，月成本列直接按新口径重排。
