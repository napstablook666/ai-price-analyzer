# 站点与插件 🧩

站点是扩展的基本单位。一个站点 = 一份采集配置 + 一个可选的站点插件。扩展默认不装插件，你装过插件、加过的站才会被采集。

## 插件从哪来

采集逻辑写在插件里，插件源码维护在独立仓库 [ai-price-analyzer-plugins](https://github.com/napstablook666/ai-price-analyzer-plugins)，一个站点一个目录。构建脚本把插件生成到扩展里：

```
plugins/<id>/manifest.json    站点元信息：名称、域名、标签
plugins/<id>/plugin.js        采集逻辑：接口、解析、登录方式
plugins/<id>/models.json      可选的模型别名表
        ↓  node scripts/plugin-build.mjs
src/site-plugins/providers/<id>.js
src/site-plugins/catalog.js
```

生成物不要手改，改完插件源码跑一次构建，测试会检查漂移。

扩展默认不装任何插件。装哪个由你在设置页的「插件仓库」里决定：填仓库地址（默认指向插件仓库公开的 `plugins.json`）、点「刷新仓库」、勾选需要的插件再点「安装所选」。装好的进入「已安装」，同一个插件只有一份，来源用徽章标出来。仓库列表和「已安装」都有「全选」，一次能装或卸一批；表格行的勾选框支持 Shift 连选一段。

| 徽章 | 来源 | 什么时候出现 |
| --- | --- | --- |
| 仓库安装 | 从线上 `plugins.json` 装 | 正常路径 |
| 本地插件 | 开发模式里手工加载的 JSON | 只在打开「开发模式」时可加载，关掉会一并卸载 |

没装的插件不参与地址匹配，也不会出现在「已安装」里。

## 添加站点

打开「站点与设置 → 已安装」，两种方式。

### 按网址分析

1. 点「添加站点」，填站点网址。
2. 点「分析站点」。扩展打开该站页面，在页面上下文里试探价目接口、价位页结构和登录方式。
3. 识别成功会弹出「确认站点配置」：站点名称、地址、采集模式、接口路径、请求方式 / 响应格式、认证方式、请求体，以及充值比例。
4. 核对无误后点「确认并添加」。

识别不出来时也能保存，只是要多填几个字段。字段含义见[站点配置字段](../configuration/station-fields)。

### 从已安装的插件里选

插件写死了接口和解析规则的站点，用这种方式最省事。

1. 先到「插件仓库」装插件：确认仓库地址，点「刷新仓库」，勾选需要的站点插件再点「安装所选」。装好的会出现在「已安装」。
2. 插件带默认站点的，安装时就顺手把站点加进工作区了；没带的（比如按地址添加的插件、签到插件）在「已安装」里点那一行右侧的「添加站点」。
3. 站点卡片就挂在插件行下面，点卡片上的齿轮补 Token 或账号。

移除插件会连它下面的站点一起删掉，站点凭证同时清掉。批量移除用「已安装」顶部的「全选」+「移除所选」。

仓库拉取失败时状态行会写失败原因和时间，已装过的插件不会因此被卸载。

## 站点挂在插件下面

插件就是站点适配器：一个插件可以带多个站点（同一个插件在不同地址的租户各算一个）。站点卡片显示在对应插件行下面，每张卡片上：

- **开关**：参与比价与批量查询。
- **齿轮**：站点配置，改完在弹层里单独保存，不走「保存全部」。
- **刷新**：查这个站点的模型与价格。
- **垃圾桶**：删除这个站点。

没有归属插件的历史站点会集中在「未关联插件」一组。

改开关后点**页面顶部的「保存全部」**才生效。

## 站点状态

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 正常 | 最近一次采集成功 | 无 |
| 待登录 | 站点要求会话，但当前没有可用登录态 | 填 Token，或手动登录站点 |
| 无凭据 | 插件声明了认证，但你还没填 Token / 账号 | 打开站点配置补凭据 |
| 采集失败 | 接口报错、解析不到价格、站点改版 | 看错误信息，先单独刷新该站 |
| 已停用 | 开关关闭 | 需要时启用 |

状态和错误码在面板的「站点 / 分组」列和站点配置里都能看到。

## 站点配置里放什么

| 字段 | 用途 |
| --- | --- |
| 站点名称 | 面板里显示的名字，重名会加后缀 |
| 站点地址 | 站点根地址，用于识别、注入和打开页面 |
| 采集模式 | 接口采集、页面采集、插件自定义 |
| 接口路径 | 价目接口的相对路径 |
| 请求方式 / 响应格式 | GET 或 POST；JSON、HTML 或自动 |
| 认证方式 | 无需认证、Token 注入、表单登录、手动 Cookie |
| 请求体 | POST 时的请求体模板 |
| Token / 密钥、用户名 / 密码 | 只存在扩展会话存储，不导出 |
| 充值金额、币种、到账中转币 | 换算充值比例 |
| 基础价 / 1M USD | 站点自己的计价基准 |
| 币种已核实、核验备注 | 记录你确认过的价格口径 |

逐项解释和取值建议见[站点配置字段](../configuration/station-fields)。

## 一个站点的采集分包

同一站点可以拆成多个「分组」，比如 `default`、`claude`、`premium`。分组只在展示和比较时生效，不影响采集配置。分组名出现在报价表的「中转站」列，筛选栏里可以多选。

## 删站之后

批量删除只删扩展里的配置和该站快照，不会动站点本身，也不会删你连过的本地工作区文件。要彻底清干净，删站后再到「数据与工作区」里导出一次，覆盖旧备份。
