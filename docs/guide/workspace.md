# 工作区与备份 💾

扩展的数据默认存在浏览器本地。要跨浏览器、跨设备，或者想放进版本库，就连一个本地工作区文件。

## 工作区是什么

工作区是一个**目录**加目录里的一个固定文件：`ai-price-analyzer.workspace.json`。

文件内容：

```json
{
  "format": "ai-price-analyzer-workspace",
  "version": 1,
  "updatedAt": 1730000000000,
  "state": {
    "stations": [],
    "snapshots": [],
    "settings": {},
    "references": {}
  }
}
```

`stations` 里存站点配置，但登录凭据不落盘：`auth` 只保留 `type`，`token`、`username`、`password` 会被抹掉。换设备后要重新填。

## 连接本地工作区

1. 打开「站点与设置 → 数据与工作区」。
2. 点「选择工作区」，在系统目录选择器里选一个目录（不是选文件）。
3. 点「保存到工作区」把当前状态写进该目录的 `ai-price-analyzer.workspace.json`；或「从工作区加载」用文件覆盖当前状态。

限制说明：

- 目录选择器需要 Chromium 系浏览器，且必须在用户点击里调用；不支持的环境会提示改用 JSON 导入导出。
- 目录授权会记住，但浏览器回收权限或扩展重载后需要重新选一次目录。
- 读写用的是一个串行队列，连着点两次保存不会互相覆盖。

## JSON 导出与导入

不选目录也能用：

- **导出 JSON**：下载一份 `{ version, exportedAt, settings, references, stations, snapshots }`，站点同样经过脱敏。
- **导入 JSON**：覆盖当前数据，导入前会提示影响范围。

导入有硬限制：

| 限制 | 值 |
| --- | --- |
| 站点数 | ≤ 100 |
| 快照数 | ≤ 500 |
| 单条记录大小 | ≤ 2 MB |
| 快照保留 | 只导入最近 30 天 |
| 参考数据大小 | ≤ 2 MB |

超限直接报错，不会部分写入。导入是覆盖不是合并，想留底就先导出一份。

## 什么时候该备份

- 刚配好一批站点。
- 调整完成本口径。
- 升级扩展前。
- 换浏览器、换电脑前。

## 卸载与恢复

卸载扩展会清掉本地存储，工作区目录里的文件还在。重装后重新选目录、点「从工作区加载」即可恢复。凭据要重新填。

## 冲突与损坏

| 现象 | 处理 |
| --- | --- |
| 加载后站点全没了 | 文件被截断或是空对象，用备份覆盖 |
| 提示「工作区文件版本不受支持」 | 文件由更新版本写出，升级扩展或用 JSON 导出迁移 |
| 提示「工作区权限已失效」 | 重新选一次目录 |
| 站点在但全部待登录 | 正常，凭据不随文件走 |
| 导入报「快照格式不正确」 | 文件被手改过，或不是本扩展导出的 |
| 保存提示无法写入 | 目录只读或被占用，换目录 |
