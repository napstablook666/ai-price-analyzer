# 故障排查 🧯

按「症状 → 先查 → 再查」的顺序走。一次只改一个变量，改完立刻验证。

## 采集相关

### 站点显示「采集失败」

1. 单独刷新该站点，看错误信息。
2. 打开站点首页能不能访问（改域名、挂了吗）。
3. `baseUrl` 是否带协议、是不是根地址。
4. 需要登录吗？看是否返回 401/403。

### 预检里站点显示「需要登录」

站点要会话但当前没有可用登录态。填 token，或按[登录与会话](./guide/session)里对应站点类型的做法处理：`page` 模式用浏览器登录态，接口模式填认证字段。

### 预检里站点显示「需人工确认」

扩展拿不到明确的登录信号：可能站点用了非常规认证头，也可能页面结构变了。先在浏览器里打开该站确认已登录，再单独刷新一次；仍然不行就打开站点配置点「测试连接」，看返回的状态码与错误原文。

### 采集成功但价格是 0

接口返回了模型列表但没带价格字段，或者字段名变了。看快照原文里有没有 `pricing` 之类的字段，必要时手选 `responseFormat`。

### 页面模式采不到

- 目标站点标签页要开着，或让扩展自己打开。
- 先在标签页里登录一次。
- 站点有 `iframe` 或跨域限制时可能读不到。

## 数字相关

### 所有价格差 1000 倍

`priceCurrency` 单位错。每 K 和每 M 相差 1000。

### 月成本算出来是 0

- 月用量字段全是 0。
- 该档位在站点返回里不存在（状态会标「中转价格未收录」）。
- 币种待核验导致折算被跳过。

### 价差不显示

模型没匹配上基准价。开「显示未匹配」能看到这些行。

### 改了汇率没反应

汇率只影响本地折算，改完保存就按新值重算，不需要重新采集。面板还没变就切一下比较来源、或重新打开面板。

## 界面相关

### 面板空白

先重载扩展：`chrome://extensions` → 该扩展的刷新按钮。还空白就看 service worker 的控制台（点「service worker」链接）。

### 设置页保存没生效

设置页是自动保存的：输入停下约 0.4 秒就落库，切走标签页或关页面时还会补存一次。写不进去会弹红色「设置保存失败」。站点配置弹层里的字段是单独保存的，两者不互通。

## 采集与基准价都不动

基本上只有一个原因：还没装插件，或者已装插件里没有可添加的站点。去「已安装」看有没有启用中的站点。

## 提交问题时要带什么

- 扩展版本（`chrome://extensions` 里能看到）。
- 出问题的站点名（不用贴 token）。
- 错误提示原文。
- 快照里对应模型的原始 JSON（去掉敏感字段）。
